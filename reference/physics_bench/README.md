## シナリオ

| ID | 内容 | 何を測るか |
|---|---|---|
| A `fd_periodic` | 周期境界の一方向通路 20m × 3m(周期像=ゴーストで厳密な周期性)。密度 0.2〜3.0 /m² | 基本図(密度-速度)。Weidmann(1993) と重ね描き |
| B `counterflow` | 幅員違い通路の対向流 200 体。幅 3m×長 60m / 幅 6m×長 30m(**面密度を 1.11 /m² に揃える**) | レーン形成(方向分離度 φ とその帰無値)・速度・重なり |
| C `crossing` | 開放正方領域 20m × 20m の 4 方向交差流(スクランブル風)200 体・壁なし | 速度効率・最小間隔・重なり |
| D `gate_stitching` | B と同じ通路で流入/流出ゲート規則を `blind` / `guarded` に変えて対照 | 境界縫合性(急停止・振動・瞬間移動・重なり) |

ゲート方式:

* **blind** — 出口を越えた個体を占有チェックなしで即入口へ再投入(P3 の素朴実装)。
* **guarded** — 出口を越えた個体は待機列(遠方の駐機スロット)へ退避。入口候補が空いている個体だけ
  id 昇順で入場させ、**退場時の速度をそのまま復元**する(P3 の「初速をグラフ側から連続に引き継ぐ」に対応)。

## 公平性のために両候補で揃えた条件

* 初期配置・希望速度 `v0` ∈ [1.0,1.4) m/s・半径 `radius` ∈ [0.25,0.35) m
  (`indoor_flow.desired_speed` / `body_radius` = agent_id の blake2b 安定ハッシュ由来)
* 近傍上限 12 体(`indoor_flow.NEIGHBOR_CAP`)、最高速度 = 1.3·v0(`sfm_core.V_MAX_FACTOR`)
* 壁の線分集合、物理 dt、記録方法、指標の計算コード

## 既知の限界(P2 分)

* `orca_min.py` の障害物処理は半平面近似(RVO2 の障害物 ORCA を移植していない)。直線壁の通路では
  ほぼ等価だが、鋭角コーナー・薄い障害物では RVO2 と挙動が変わりうる。
* 基本図の密度は測定矩形内の頭数/面積(古典法)。Voronoi 法(Steffen & Seyfried 2010)は未実装。
* レーン形成の秩序変数は自前定義(横断ビンの方向分離度)。Feliciani & Nishinari (2016) の
  2 次元 order parameter とは別物。有限サイズのベースライン(方向ラベル無作為化)を必ず併記している。
* 実 LLM も本体シミュレータも一切動かさない。ここで測っているのは物理層単体の性能だけ。

**加工内容の申告**(CC BY 4.0 の "indicate if changes were made"):

1. 座標の単位を **m に統一**(2009 HERMES と 2013 crossing_90 は cm、2013 uni_corr は m)。frame → 秒(÷ fps)。
2. **z 列(頭部高さ / 3D 位置)を捨てた**(2D 較正のため)。単位判定の手がかりとしてのみ読む。
3. 速度 = 位置の**中心差分**(窓 ±0.5 s = 全窓 1.0 s)。両端 0.5 s は速度を持たないので落とす。
4. 測定区画内の**古典密度**(頭数 ÷ 面積)と、区画内個体の**流れ方向速度成分の算術平均**。
5. **0.5 s ごとに間引いて標本化**(生は 16 fps)。
6. 密度ビン(幅 0.1 /m²)ごとに平均・標準偏差・**10/90 パーセンタイル**へ集計。
7. **生の軌跡そのものは再配布していない**(集計統計のみ)。

### 1.4 測定区画(本ベンチの選択。文献の指定ではない)

一方向流は **流れ方向 2 m × 通路全幅** の矩形を通路の中央に置きます。
RiMEA Test 4 が指定する 2×2 m は通路幅 2 m 未満の実験(ug-100 = 1.0 m 等)には置けないため、
「流れ方向 2 m」だけを共有し、横断方向は通路全幅を採りました(Jülich の慣行と同じ)。
交差流は中央に 2×2 m(RiMEA Test 4 の寸法どおり)。
通路本体は **`parameter` の通路幅 b を一次情報**とし、WKT の内部区間のうち
**幅が b に最も近いもの**を選びます(壁の切欠き=ドア枠に引っかからないよう、
壁の bounding box ではなく **線分と多角形の厳密な交点**で内部区間を切り出しています)。

### 1.6 実測から得た参照値

**基本図**(全 3 実験を合わせた定常標本の密度ビン平均。単位 m/s):

| ρ [1/m²] | Jülich 合成 | 閉境界のみ | 開境界のみ | BaSiGo のみ | Weidmann 1993 |
|---|---|---|---|---|---|
| 0.5 | **1.33** | 1.13 | 1.44 | 1.27 | 1.298 |
| 1.0 | **1.11** | 1.01 | 1.32 | 1.13 | 1.058 |
| 1.5 | **0.84** | 0.87 | 1.02 | 0.85 | 0.807 |
| 2.0 | **0.58** | 0.53 | 0.68 | 0.59 | 0.606 |
| 3.0 | **0.28** | 0.18 | 0.35 | 0.17 | 0.331 |

**合成 FD は Weidmann とよく一致します**(全点 ±10% 以内)。Weidmann は 25 研究の統合
レビューなので、これは「パーサと測定プロトコルが壊れていないこと」の実測的な裏づけになります。
一方で**境界条件による差は大きい**(ρ=1.0 で閉 1.01 vs 開 1.32 = 31% 差)ことも見えており、
これは研究文書 §2.2 の「研究間ばらつき ±20%」と整合します。

Kladek 式を合成データに当てはめると **v_f = 1.414 m/s, γ = 1.656 m⁻², ρ_max = 5.055 m⁻²**
(Weidmann の 1.34 / 1.913 / 5.4 に近い)。`calibrate.py` はこの曲線の **v_f だけを
シムの平均希望速度に差し替えたもの**を参照にします(理由は同スクリプトの docstring)。

**ボトルネック**(HERMES 5 run):

| b_Exit [m] | 参加者 | 通過 | J [1/s] | **J/b [1/(m·s)]** |
|---|---|---|---|---|
| 2.4 | 400 | 350 | 6.06 | **2.52** |
| 3.0 | 400 | 348 | 7.16 | **2.39** |
| 3.6 | 400 | 349 | 8.95 | **2.49** |
| 4.4 | 400 | 348 | 10.89 | **2.47** |
| 5.0 | 400 | 348 | 13.73 | **2.75** |

J/b は幅にほぼ依存せず **2.39–2.75**。研究文書 §2.4 が引く参照値 **≈1.9 (m·s)⁻¹ は
b = 0.6–2.5 m の範囲**の値なので、**本実測(b = 2.4–5.0 m)は 26–45% 高い**ことになります。
理由は(i)幅の範囲が違う、(ii)本ベンチの定常部の取り方(通過ランク順の中央 80%)が
文献と同一とは限らない、の 2 つが考えられ、**どちらであるかは確認できていません**。
→ **受入判定には文献値 1.9 の帯 [1.5, 2.3] を使い、本実測値は併記**しています。

**★シムと実測の開口幅が重なっていない**: シム側の掃引は w ∈ {0.8, 1.0, 1.2, 1.6, 2.4} m
(RiMEA/Seyfried の標準域)、Jülich 実測は b ∈ {2.4, 3.0, 3.6, 4.4, 5.0} m。
**重なるのは 2.4 m の 1 点だけ**です。

**★長距離項の近傍上限は既定 None(上限なし)**。理由: ρ=3 /m² では最近傍 12 体はすべて

`FAR_CUTOFF_FACTOR = 2.5` + `far_taper = 1.0 m` とセットでしか意味を持ちません
(切って失う裾を A2 が吸収するため)。**P4-2 で本体へ移すときは同じ規則をそのまま持ち込むこと。**

## 5. P4-1 の既知の限界(正直な申告)

1. **RiMEA 公式の Test 16 パーセンタイル XLSX を読めていません。** `openpyxl` がこの環境に
   未導入で(`pandas` も未導入)、XLSX を解く手段がありません。代わりに **Jülich 実測から
   同じ流儀(密度ビンごとの 10/90 パーセンタイル)で包絡線を作って**います。
   RiMEA の包絡線は**単列(1D)歩行**の集成なので、そもそも本ベンチの 2D 通路と直接は

## 8. ★新発見: ρ_global ≥ 2.0 の FD 点は「壁貫通で個体が消えた系」を測っている

周期通路 20 m × 3 m・dt=0.05・t=60 s・現行 src 既定での**通路外へ出た個体数**(実測):

| ρ_nominal | 0.5 | 1.0 | 1.5 | **2.0** | **3.0** |
|---|---|---|---|---|---|
| N | 30 | 60 | 90 | 120 | 180 |
| 通路外へ出た個体 | 0 | 0 | 0 | **27** | **90** |

* 原因は**初期配置**です。`_init_positions` は棄却サンプリング(400 試行)で、
  半径 ~0.30 m の円板が面積率 57%(ρ=2.0)・**85%(ρ=3.0)** になると
  ランダム逐次吸着の詰まり限界(≈0.55)を超えて置けず、**重なったまま配置されます**。
  重なりの対人斥力は 1 ペアあたり最大 `A·e⁴ = 109 kN`(= 1365 m/s²)で、
  近傍数体ぶんの合力が **壁 1 セグメントの同じ上限**を上回ります。
  さらに `v_max` クリップは**速さだけ**を切って向きは合力のままなので、
  個体は 1.5 m/s で壁へ歩き続け、4 サブステップで中心が壁線を越えます。
  **中心が越えた瞬間に壁法線の向きが反転**し、以後は外向きに押され続けて永久に戻りません。
* **WALL_B を縮めても直りません**(実測・ρ=3.0 で通路外へ出た個体):
  b=0.08 → **90** / 0.05 → 89 / 0.03 → 89 / 0.02 → 84。
  根本原因は `sfm_core` が**意図的に省いた接触項(body force / friction)**の不在と
  `v_max` クリップの組み合わせで、壁パラメータのレバーでは届きません。
* **含意**: P4-1 が報告した「ρ=3.0 で +2.9 倍」の非単調性は、
  **半数の個体が消えた別の系**を測った値を含みます。
  `calib_p43_results.json` は密度点ごとに `escaped_agents` を必ず併記し、
  判定 B は「全点」と「**貫通ゼロの点だけ**(`B_monotonic_clean`)」の 2 本立てにしました。
  **ρ_global ≥ 2.0 は現行パラメータでは本ベンチの有効範囲外**として扱ってください。

## 10. V(s) の較正(Tordeux, Chraibi & Seyfried 2015)

**式**(研究文書 §4.1・原論文の使用値は v0=1.2 m/s, ℓ=0.3 m, T=1 s):

```
V(s) = min{ v0 , max{ 0 , (s − ℓ)/T } }
```

**駆動項の希望速度だけ**を V(s) に差し替えます(方向モデル・斥力・v_max・λ は SFM のまま)。
純度低下の防御は研究文書 §4.3(JuPedSim が Collision-Free Speed Model を製品実装)。

**s の定義(本ベンチの選択。原論文は単列歩行なので 2D への持ち上げが要る)**:
進行方向成分 `(x_j − x_i)·e_i` が正、かつ横ずれが体半径和 `(r_i + r_j)` 以内の相手だけを
「前方」と数え、その最小の**中心間距離**を s とする(前方に誰も居なければ s = ∞ → V = v0)。
円錐角ではなく**体幅ぶんの回廊**で切るのは、すれ違いざまの相手で速度が落ちないようにするため。
**ℓ は原論文の 0.3 を借りません**(あちらの体長 0.3 m に対し本リポジトリの体径は 0.5–0.7 m)。

**探索**: 粗グリッド T ∈ {0.15,0.3,0.55,0.9} × ℓ ∈ {0.2,0.4,0.6} を
far_field **ON / OFF の両方**(= 4 変数目)で回し、勝った側で Nelder-Mead 20 評価。
壁は §9 の推奨 b=0.03 に固定。目的関数は §7 の局所測定 FD + 単調性 + ボトルネック。

| 段 | 結果 |
|---|---|
| 粗グリッド far=ON | 最良 loss **0.1759** @ (T,ℓ)=(0.55, 0.2) |
| 粗グリッド far=OFF | 最良 loss 0.2337 @ (T,ℓ)=(0.55, 0.4) |
| Nelder-Mead(far=ON) | 最良 loss **0.1282** @ **(T,ℓ)=(0.4823, 0.2965)** |

→ **far_field は ON の方が良い**(loss 0.176 vs 0.234)。**推奨**:

> **v_of_s (T, ℓ) = (0.482 s, 0.297 m)・far_field (A2,B2)=(0.119, 1.890)・
> cutoff 2.5·B2 + テーパー 1.0 m・WALL_B = 0.03・λ = 0.5・dt = 0.05**

3. **判定 B の合格は弱い証拠**です。§8 のとおり ρ_meas が 1.5 付近で頭打ちになり、

## 12. P4-3 の既知の限界(正直な申告)

1. **ρ_global ≥ 2.0 の 2 点は壁貫通で個体が消えた系**です(§8)。判定に含めていますが、
   `escaped_agents` を必ず併記し、貫通ゼロの 3 点だけの判定も別掲しています。
   **この 2 点を根拠に何かを主張してはいけません。**
2. **測定密度が ρ ≈ 1.5 で頭打ち**になり、FD の高密度側(領域 III–IV)を測れていません。
   周期通路 20 m × 3 m という幾何と、半径 0.25–0.35 m・接触項なしという
   パラメータの組み合わせの限界です。
3. **D(J/w)の水準不足は未解明のまま**です。P4-1 の仮説「壁斥力が主因」は、
   B_w を 0.08 → 0.02 に縮めても J/w が 1.1 倍前後しか上がらないことで**部分的に否定**されました。
   残る候補は (a) 接触項(body force / friction)の不在、(b) 駆動項 τ=0.5 s、
   (c) v0 分布(シム 1.19 vs 実測 1.41 m/s)、(d) 定常部の取り方 —— **切り分けていません**。
4. **V(s) の「前方」定義は本ベンチの選択**で、原論文にも JuPedSim にも
   「体幅回廊で切る」という記述は確認していません(2D への持ち上げは実装者の裁量)。
5. **総計算 15.5 分**(指示の 45 分以内)。壁格子 6 水準 × 6 幅、V(s) 格子 4×3 × far 2 水準、
   NM 20 評価、最終評価 4 条件。**間引きはしていません**が、
   探索ループの密度点は P4-1 と同じく ρ ∈ {0.5,1.0,1.5,2.0}(最終評価だけ 3.0 を含む)。
6. **λ・A2・B2 は再探索していません**(P4-1 の確定事項として受け取った)。
   壁を変えると対人項の最適点も動きうるので、**厳密には (λ, A2, B2, T, ℓ, B_w) の
   同時最適化が要ります**。本バッチは 45 分予算で段階的に解いた近似です。
7. **Voronoi 密度は依然として未実装**(P4-1 の限界 2 のまま)。
